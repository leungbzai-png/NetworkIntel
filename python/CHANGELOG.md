# NetworkIntel GUI - Changelog

## v1.2.0  (2026-06-05)
- ✨ **新功能：地图可视化**（批量查询页 → "地图" Tab）
  - Leaflet + OpenStreetMap 国际版（中性显示，TW 独立标注）
  - flagcdn.com 国旗图标（TW = 青天白日满地红）
  - 按风险等级着色（红/橙/黄/蓝/绿）
  - 自动 fit bounds，相同坐标自动抖动避免重叠
  - 风险图例
- ✨ 状态栏显示版本号
- 🔧 打包脚本支持 QtWebEngine 自动收集
- 🔧 新增 backup.bat（备份 yaml + db + 代码）
- 🔧 新增 update.bat（一键备份 + 重新打包）

## v1.1.0  (2026-06-05)
- ✨ 新增「网络」页面（F3）含 3 个 Tab：
  - ASN 反查（按 ASN 列出全部前缀）
  - 国家统计（TOP ASN / 城市分布 / 威胁估算）
  - CIDR 段查询（段内 ASN / 威胁 / 云覆盖）
- ✨ 新增「威胁库」页面（F4）
  - 按来源 / 类型 / 严重度筛选
  - 网络/IP 搜索 · 分页 · 导出 CSV
- ✨ 查询页顶部新增数据库统计仪表盘

## v1.0.0  (2026-06-05)
- 初版 PySide6 GUI
- 6 页面：查询 / 批量 / 数据源 / 调度 / 报告 / 设置
- 浅色 + 深色 + 跟随系统主题
