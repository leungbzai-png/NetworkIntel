NetworkIntel v0.3.0 — Portable Windows x64（测试版 / RUNNING.txt）
============================================================

1. 这是 NetworkIntel v0.3.0 Portable Windows x64 测试版。
   （v0.3.0：数据源更新走统一串行队列，「全部更新」进行中再次点击会提示任务正在执行。）

2. 可解压到任意目录运行（不再锁定 E:\NetworkIntel）。

3. 首次运行会在本目录自动创建：
   configs/  live/  cache/  logs/  reports/  snapshots/  backups/

4. 推荐在 GUI 设置页（F8 →「API KEY」）填写 MaxMind Key。
   Key 仅写入本目录的 .env，绝不进入 Git，也不写入 sources.yaml 明文。

5. 可在 GUI「数据初始化」界面选择数据源方案：
   最小 / 推荐 / 完整 / 自定义。

6. 默认数据目录跟随程序目录（portable 模式：数据放在 exe 所在目录）。

7. 可在设置页改为「自定义数据目录」（custom 模式），
   把 live/cache/logs/... 放到指定盘符或目录。

8. 数据库不随包发布。首次运行后请在「数据初始化」界面自行选择数据源并下载更新。

9. API key 不随包发布。在线增强 key 为可选项；本地数据库初始化只有 geoip 需要 MaxMind Key（缺它仅跳过 geoip）。

10. 如被杀毒软件误报，属于 PyInstaller 打包的常见情况，请自行判断是否信任并加入白名单。
